# Lorenzo Italiano — Research Page

A lightweight static page designed for the QR code on the GTTI 2026 poster.

## Recommended GitHub Pages setup

For a permanent personal URL, create the repository **`Ita97.github.io`**. GitHub Pages will publish it at:

`https://ita97.github.io/`

If you already use that repository for another website, create a normal repository such as `gtti2026` instead; the page will then be available at:

`https://ita97.github.io/gtti2026/`

## Publish step by step

1. Sign in to GitHub with the account `Ita97`.
2. Click **New repository**.
3. Set the repository name to **`Ita97.github.io`** (recommended) or `gtti2026`.
4. Set the repository to **Public** and create it.
5. On the repository page, choose **Add file → Upload files**.
6. Upload these items from this folder to the repository root:
   - `index.html`
   - `styles.css`
   - the entire `assets` folder, containing `lorenzo-italiano.png`
7. Commit the uploaded files to the `main` branch.
8. Open **Settings → Pages** in the repository.
9. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait briefly for GitHub Pages to deploy the website.
12. Open the URL shown in **Settings → Pages** and test it on both desktop and smartphone.
13. Open all publication and profile links to verify that they work.
14. Use the final GitHub Pages URL as the destination of the QR code on the poster.

## Updating the page later

Edit `index.html` directly on GitHub or upload a modified version and commit the change. GitHub Pages will automatically redeploy the website. This is useful when preprints become published papers or DOI links change.
